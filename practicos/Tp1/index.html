Clases De Etiquetas HTML

Estructura mínima de un documento HTML

<!DOCTYPE html>→ Indica que el documento es HTML5.

<html> → Encierra todo el contenido de la página.

<head> → Contiene metadatos (información que no se muestra directamente en la página).

<title>→ Título que aparece en la pestaña del navegador.

<meta> → Información como codificación (UTF-8), descripción, autor, etc.

<link> → Para enlazar hojas de estilo CSS.

<body> → Todo el contenido visible de la página (texto, imágenes, botones, etc.).

Etiquetas básicas de contenido

Dentro del <body> se usan etiquetas para organizar la información:

ENCABEZADOS:

<h1> a <h6> → Títulos y subtítulos (h1 es el más importante).

PARRAFOS

<p> → Bloques de texto.

ENLACES

<a href="..."> → Hipervínculos a otras páginas o secciones.

IMAGENES

<img src="..." alt="..."> → Insertar imágenes.

LISTAS

<ul> Lista desordenada (con viñetas).

<ol> → Lista ordenada (numerada).

<li> → Elemento dentro de una lista.

DIVISIONES Y SECCIONES

<div> y <section> → Agrupan contenido.

BOTONES

<button> → Botón interactivo.

DORMATEO DE TEXTO

<strong> → Texto en negrita.

<em> → Texto en cursiva.

<br> → Salto de línea.
